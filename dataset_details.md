# Dataset Details

This project uses publicly available financial transaction datasets obtained from Kaggle.

## Datasets Used

- Daily Household Transactions Dataset  
  https://www.kaggle.com/datasets/prasad22/daily-transactions-dataset

- Spending Habits Dataset  
  https://www.kaggle.com/datasets/ahmedmohamed2003/spending-habits

- Financial Transactions Dataset — Expenses and Income  
  https://www.kaggle.com/datasets/artemkabseu/financial-transactions-dataset-expenses-and-income

- Credit Card Dataset — Comprehensive  
  https://www.kaggle.com/datasets/aadarshvani/credit-card-dataset-comprehensive

## Notes

All datasets were used for academic and research purposes only.
